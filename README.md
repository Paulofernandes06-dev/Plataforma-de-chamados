# 🏥 Sistema de Chamados - Hospital Beneficência Portuguesa (HBP) - https://paulofernandes06-dev.github.io/Plataforma-de-chamados/

Este é um sistema de gestão de chamados técnicos desenvolvido para otimizar a comunicação entre os setores assistenciais e as equipes de manutenção/TI do hospital. O projeto foca em agilidade, facilidade de uso em desktops e notificação em tempo real via WhatsApp.

## 🚀 Funcionalidades

- **Abertura de Chamados:** Interface intuitiva para enfermagem e médicos solicitarem reparos.
- **Painel de Controle:** Visão exclusiva para técnicos gerenciarem demandas pendentes, em andamento e concluídas.
- **Status em Tempo Real:** Página de consulta rápida para os setores acompanharem o progresso das solicitações.
- **Integração com WhatsApp:** Envio automático de resumo do chamado para o celular do técnico responsável.
- **Persistência de Dados:** Utilização de LocalStorage (ou banco de dados) para manter o histórico de atendimentos.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica para acessibilidade e SEO.
- **CSS3:** Layout responsivo focado em desktop, utilizando Flexbox e Grid.
- **JavaScript (Vanilla):** Lógica de manipulação de dados, armazenamento e integração com API do WhatsApp.
- **Identidade Visual:** Inspirada nas cores institucionais do HBP (Azul Real e Branco).

## 📂 Estrutura do Projeto

- `index.html`: Página principal para abertura de chamados.
- `painel.html`: Dashboard de gestão para a equipe de manutenção.
- `status.html`: Lista pública para acompanhamento de ordens de serviço.
- `estilo.css`: Folha de estilo centralizada para todo o sistema.

## 🏁 Como rodar o projeto

1. Faça o clone deste repositório:
   ```bash
   git clone https://github.com
   ```
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Para acesso em rede local (Intranet), hospede os arquivos em um servidor (IIS, Apache ou Live Server) e acesse via IP da máquina.
